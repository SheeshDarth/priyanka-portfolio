# Design concepts

Scored 1–5 on: credibility, originality, authenticity, accessibility, mobile, performance, maintenance.

## A — Engineered Editorial *(selected)*
- **Thesis:** a technical magazine. Giant condensed type, hairline rules, mono labels, light porcelain surfaces broken by one asphalt-dark "open road" section.
- **Type:** Barlow Condensed (display) + IBM Plex Sans + IBM Plex Mono labels.
- **Palette:** Asphalt, Graphite, Steel, Signal Copper (a darker copper-ink for text on light), Porcelain.
- **Hero:** the name set enormous; a drawn trajectory marks brief → spec → build → review → test → ship.
- **Signature interaction:** the Journey Line, a scroll-linked rail that doubles as section navigation.
- **Without photos:** works fully (typographic). **Risks:** can feel cold; mitigated by warm copy and the dark section.
- **Scores:** 5 / 4 / 5 / 5 / 5 / 5 / 5.

## B — Momentum / Open Road
- **Thesis:** one continuous road line connecting every section; riding imagery leads.
- **Without photos:** weak, because the concept relies on imagery that does not exist yet, and it risks over-weighting riding versus engineering.
- **Scores:** 3 / 4 / 3 / 3 / 3 / 3 / 3.

## C — Modern Independent
- **Thesis:** minimal personal brand led by a portrait.
- **Without photos:** nothing to lead with; would need stock or invented imagery, which the brief forbids.
- **Scores:** 3 / 3 / 2 / 5 / 4 / 5 / 5.

**Decision:** A, borrowing B's road motif for a single closing section and C's restraint.
